# Web Dashboard

Next.js dashboard for the Google Maps Business Scraper.

## Features

- Scrape Google Maps from the browser UI
- Browse, search, sort, and filter scraped leads
- Edit / delete / bulk delete leads
- Send WhatsApp messages (individual or bulk)
- WhatsApp connection status and QR pairing
- Real-time scraping progress

## Setup

```bash
cd web
npm install
```

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The dashboard expects the Go API server running on the same host (port 8080).

## Build

```bash
npm run build
npm start
```
